## Project Overview

Backend API for Grupo Intecsa built with Node.js, Express, and Mongoose. It manages inventory, fleet logistics (flotillas), HR attendance (checa), quotations/invoices, and integrations with Monday.com, Twilio, and external PDF services.

## Common Commands

- `npm start` — Run the server in production mode (`node server.js`)
- `npm run dev` — Run with nodemon for development
- `npm test` — Run the Jest test suite (`jest --verbose`)
- `npx standard` — Lint with StandardJS (installed but not configured in package.json scripts)

## Environment & Configuration

- `NODE_ENV` determines the MongoDB database: `test`, `prod`, or `catv2` (see `config/index.js`)
- MongoDB is hosted on Atlas (`gti.tcrun.mongodb.net`)
- Firebase, Cloudinary, Twilio, and MailerSend credentials are loaded from `.env`
- `PORT` defaults to 3000

## Architecture

The codebase follows a simple layered structure:

```
routes/ → controllers/ → services/ → models/
```

- **Routes** (`routes/`): Express routers mounting at `/api/v1/...`. See `routes/index.js` for the full registry.
- **Controllers** (`controllers/`): Thin HTTP handlers that delegate to services. Error handling is inconsistent — many controllers return 400 with the raw error object.
- **Services** (`services/`): Business logic and database access. Some services return Mongoose queries directly; others use async/await.
- **Models** (`models/`): Mongoose schemas. Exported via `models/index.js` barrel file.
- **Utils** (`util/`): Helpers including `aggregatios.js` (MongoDB aggregation pipelines for fleet documents), `jsonToSheet.js` (Excel export), `imageStorage.js` (GCS/Cloudinary upload), and `index.js` (JWT token creation, password comparison, date formatting).

### Fleet / Flotillas Domain

The flotillas module uses **dynamic model selection** based on a `type` query parameter (`traslado`, `flete`, `renta`). The `FlotillasService` switches between `Traslado`, `Flete`, and `Rentas` models at runtime. Complex cross-collection lookups live in `util/aggregatios.js` (e.g., `viewDocumentsNormal`, `viewDocumentsCanceled`), joining `bussiness` with fletes/traslados/rentas and looking up vehicle info from the `flotillas` collection.

### PDF Generation

PDFs are generated by rendering HTML template strings via **Puppeteer** (see `MessageController.createInvoice` and `FlotillasController.printPlan`). Invoice HTML templates are large inline strings inside `services/PDFServices.js`. The external `PDF_SERVICE` URL is also used for some PDF generation (e.g., paqueteria reports).

### Authentication

JWT auth is implemented in `middlewares/authUser.js`. The `verifyToken` middleware extracts `Bearer <token>` from the `Authorization` header and verifies it against `process.env.JWT_SECRET`. **Note:** Many routes have `verifyToken` commented out; check the specific route file before assuming an endpoint is protected.

### External Integrations

- **Twilio**: WhatsApp and email notifications (`services/TwilioService.js`)
- **Monday.com**: GraphQL mutations/queries for board items (`MessageController.getBoard`, `TwilioService.createItemOnBoard`)
- **MailerSend**: Transactional emails with PDF attachments (`controllers/EmailController.js`)
- **Firebase**: Firestore and Storage (`database/firebase.js`)
- **Cloudinary**: Image upload middleware configured globally in `server.js`
- **Google Cloud Storage**: File uploads via `multer-google-storage` (`util/imageStorage.js`)

### HR / Checa (Attendance)

The `Checa` module handles employee attendance via QR code scanning. `AttendanceEmployee` records are linked to `ChecaEmployees` by `employeeId`. The `reporter` endpoint in `ChecaController` generates Excel reports via `jsonToSheet` using aggregation pipelines in `RHService.getRegistersByDateRange`.

## Testing

Jest is configured with `testEnvironment: "node"`. The project currently has minimal test coverage. The `test/` directory only contains `serviceAccountKey.json`.

## Important Implementation Notes

- The `Bussiness` model is defined inline inside `services/FlotillasService.js` rather than in `models/`, which is inconsistent with the rest of the codebase.
- `empresaLogos` is a hardcoded lookup array in `services/PDFServices.js` used to resolve company names/slugs for invoices.
- `PDFServices.createInvoice` and `flotillaInvoice` return HTML strings, not PDF buffers — the caller (controller) runs Puppeteer to convert to PDF.
- `server.js` applies CORS headers manually in addition to the `cors()` middleware.
